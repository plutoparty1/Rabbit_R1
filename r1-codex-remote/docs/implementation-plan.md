# 이번 작업 범위와 실행 기록

1. 기존 AGENTS 지시·Git 변경·첨부 명세를 읽고 단일 에이전트로 실행합니다.
2. 버전·인증 종류·프로세스·daemon·로컬 도움말·설치 스키마를 읽기 전용으로 확인합니다.
3. 신규 `r1-codex-remote` 폴더만 사용합니다. 기존 프로젝트와 사용자 변경은 수정하지 않습니다.
4. 제품 코드 작성 전 Python 브리지 테스트와 Node PTT 테스트를 실행했습니다. 각각 `ModuleNotFoundError: No module named 'companion'`, `ERR_MODULE_NOT_FOUND`로 요구 제품 부재를 확인했습니다.
5. 진단 서버·기기 연결·버튼·Web Speech 지원 검사·마이크 녹음 검사를 구현했습니다.
6. 인증·출처·크기·요청 제한·권한 폐기·시간 제한·마이크 종료·전송 차단을 자동 검증했습니다.
7. 실제 로컬 TLS 시험과 브라우저 UI 시험을 실행했습니다. 실제 r1과 실제 한국어 인식은 미실행으로 기록했습니다.
8. 연결 증명과 실기 증거가 없는 단계 C/D는 구현하지 않았습니다. 현재 업무 세션을 변경하지 않았습니다.

프로젝트 전용 FastAPI·Uvicorn·websockets를 사용하여 HTTP/WS 프로토콜을 직접 구현하는 코드를 생략했습니다. `httpx`는 통합 테스트용입니다. 설치는 프로젝트 `.venv` 내부로 제한했습니다. 원본 로그나 인증 토큰을 수집하지 않는 진단 앱이 이번 산출물입니다.
