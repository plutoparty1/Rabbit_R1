# R1 Codex Remote — 계정 잔여 한도 상태창

2026-10-07 현재, 실제 계정 잔여 한도를 읽는 한 화면의 상태창을 구현했습니다. **진행 중인 동일 Codex 세션 연결과 음성 제어는 아직 미완료입니다.**

앱은 오른쪽 버튼 이벤트, 한국어 Web Speech 지원·최종 결과, 마이크 녹음 가능 여부, PC 브리지 통신을 따로 확인합니다. `POST /api/commands`는 항상 전송을 차단합니다. 통신 시험 응답은 Codex 응답이 아닙니다.

홈에는 계정 잔여 비율·사용 창·초기화 시각·갱신 시각을 표시합니다. 연결 코드·SDK 카운터·마이크 시험은 ‘연결·시험’ 뒤로 옮겼습니다. 계정 조회는 기존 인증을 사용하는 별도 읽기 전용 app-server로 수행하며 모델 턴을 시작하지 않습니다. 세션을 만들거나 저장 이력을 읽지 않습니다. 기본 새로고침은 60초입니다.

## 현재 결과

- PC CLI: `0.160.1`, ChatGPT 인증.
- 현재 Codex: `--no-daemon`, 서버 주소 없음. 공유 daemon 연결은 `os error 10050`으로 실패.
- PC 자동 테스트: Python 21개와 PTT 시나리오 9개 통과.
- 계정 한도: 실제 `account/rateLimits/read` 조회 및 홈 표시 검증 통과. 검사 당시 7일 한도 잔여 63%, 다음 초기화 2026-10-10 12:10 한국 시간. 값은 고정하지 않으며 실제 조회 결과로 갱신합니다.
- 브라우저 UI: 240×282, 실제 로컬 HTTP/WS 통신과 **모의** 음성·마이크 시험 통과.
- 로컬 TLS: 자체 인증서를 신뢰하도록 설정한 테스트 클라이언트의 실제 HTTPS/WSS 시험 통과. r1에서의 인증서 신뢰·접속은 미확인.
- 공개 접속: 승인 후 임시 HTTPS/WSS 주소를 발급하여 브라우저 기본 인증서 검증으로 수신·접근 차단·권한 폐기를 확인했습니다. [실제 접속 결과](docs/public-access-test.json).
- 실제 r1: 설치·앱 실행·수정 후 WSS 수신·긴 누름 시작/종료를 사용자 확인으로 검증했습니다. 단일 클릭·마이크 녹음 전용 시험·실제 한국어 인식은 아직 미검증입니다. 사용자가 현재 발화할 수 없어 한국어 인식 시험을 보류합니다.
- 기존 설정·인증 파일: 진단 전후 해시 동일. 기존 프로젝트의 변경은 그대로 유지.

## PC에서 실행

프로젝트 안에 설치된 전용 Python 환경을 사용합니다. 다음 명령은 진단 서버만 실행합니다.

```powershell
Set-Location 'C:\Users\정산-PC\jjs1124\r1-codex-remote'
.\scripts\start.ps1
```

브라우저에서 `http://127.0.0.1:8787/`을 열고 터미널의 8자리 코드를 입력해 주세요. 코드는 2분 동안 한 번만 사용할 수 있습니다. 시험 기기를 바꾸거나 코드가 만료되면 서버를 종료하고 다시 실행해 주세요. 연결 권한은 1시간 동안 유효하며, ‘연결 해제’ 또는 서버 재시작으로 폐기됩니다. 종료는 해당 진단 서버 터미널에서 `Ctrl+C`를 누릅니다.

‘통신 시험’으로 PC 응답을 확인한 뒤, 아래로 이동하여 입력 시험 방식을 선택해 주세요. ‘한국어 Web Speech’는 해당 브라우저가 실제로 제공할 때만 동작합니다. 일부 구현은 브라우저 제공업체의 인식 서버를 사용합니다. 실제 업무 내용 대신 ‘연결 시험입니다’처럼 짧은 시험 문장을 사용해 주세요. ‘마이크 녹음만 확인’은 녹음 크기와 마이크 종료만 확인하며 문장을 인식하지 않습니다. 음성 원본과 인식 문장은 PC 브리지에 업로드하지 않습니다.

결과 파일에는 이벤트·지원 여부·전송 시간·인식 글자 수만 포함합니다. 전체 문장과 녹음 파일은 포함하지 않습니다.

## r1에서 실행하려면

r1의 `127.0.0.1`은 r1 자체입니다. 위 PC 내부 주소로는 접속할 수 없습니다. 이전 주소는 약속한 시간에 종료되었습니다. 현재 상태창 시험 주소는 `https://ordered-highly-efficient-throws.trycloudflare.com`이며 **2026-10-07 14:24:53 한국 시간**에 자동 종료됩니다. 서버·Creation을 같은 주소에서 제공하여 인증 쿠키와 WSS를 함께 사용합니다.

[설치 QR 열기](docs/install-qr.png)를 PC 화면에 띄운 뒤, r1의 creations에서 QR로 추가를 선택하고 스캔해 주세요. 앱이 열린 다음 새 일회성 코드를 발급하여 연결합니다. 설치 QR과 PC 연결 코드는 서로 다릅니다.

새 홈의 PC 브라우저 검증은 [account-dashboard-public-test.json](docs/account-dashboard-public-test.json), 실제 화면은 [account-dashboard-240x282.png](docs/account-dashboard-240x282.png)에 기록했습니다. 새 홈의 r1 실기는 아직 미완료입니다.

전체 세션은 공유 서버에 연결된 실행 세션의 이름·상태를 모아 표시하는 구조로 진행합니다. 현재 `--no-daemon` 원래 작업의 실시간 연결은 미검증이므로 실제 세션 개수·이름·응답을 표시하지 않습니다. 저장 목록이나 별도 계정 조회 서버의 빈 목록을 실행 상태로 대체하지 않습니다.

주소가 준비되면 다음처럼 진단 서버가 해당 주소만 허용하도록 실행합니다.

```powershell
.\scripts\start.ps1 -PublicOrigin 'https://실제로-발급된-주소'
```

이 명령 자체가 인터넷 주소를 만들지는 않습니다. 설치 QR에는 앱 제목·설명·공개 앱 URL만 넣습니다. PC 연결 코드, 기기 자격 증명, Codex 인증 정보는 QR에 넣지 않습니다. 구체적인 실기 순서는 [실기 시험 기록](docs/device-test-report.md)을 확인해 주세요.

## 재검증

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
node tests/test_ptt.mjs
node --check creation/app.mjs
.\.venv\Scripts\python.exe scripts/diagnose.py
```

`tests/browser-check.js`는 Playwright 도구에서 실행하는 함수입니다. 먼저 화면에서 페어링한 뒤 실행하며, 독립 브라우저 공간에서 모의 음성·마이크로 버튼과 종료 처리를 확인합니다. 실제 인식 성공의 증거로 사용하지 않습니다. 테스트는 연결 권한을 폐기합니다.

`tests/public-browser-check.js`는 실제 임시 주소의 HTTPS/WSS를 별도 브라우저 공간에서 확인합니다. 원래 페이지의 코드 입력란에 준비한 일회성 코드를 읽어 시험하며, 음성·버튼을 모의 처리하지 않습니다. 이 시험도 기기 연결을 폐기합니다. 실제 r1 연결 후에는 코드 갱신이나 이 시험을 실행하지 마세요.

시험용 통로만 종료하거나 연결 코드를 새로 발급하려면 다음 명령을 사용합니다. 갱신은 진단 서버를 재시작하므로 연결되어 있던 시험 기기는 다시 연결해야 합니다.

```powershell
.\.venv\Scripts\python.exe scripts/public_session.py --stop
.\.venv\Scripts\python.exe scripts/public_session.py --renew-code
```

코드는 PC의 `.runtime/public-state.json`에만 보관하며 앱·공개 보고서·QR에는 넣지 않습니다. 관리 프로세스는 생성한 자식 두 개만 종료하고 실행별 임시 폴더를 정리합니다. `.tools`의 검증한 도구·공식 CA 파일은 재사용 자료로 유지하며 시스템 인증서 저장소를 변경하지 않습니다.

새 설치에서는 프로젝트 내부에만 환경을 만듭니다. `requirements.lock.txt`에 실제 사용한 버전을 고정했습니다. 설치·변환의 임시 경로는 프로젝트의 `.project_tmp` 아래 실행별 폴더로 지정해 주세요. 실행 스크립트와 테스트는 자신이 만든 임시 폴더만 정리합니다. `docs`의 보고서·화면 이미지는 사용자 산출물이므로 자동 삭제하지 않습니다.
