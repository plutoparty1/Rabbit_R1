# Design

## Source of truth
- Status: Active
- Last refreshed: 2026-10-08
- Primary product surfaces: rabbit r1 Creation, 240×282 화면.
- Evidence reviewed: 사용자 요청, 기존 `r1-codex-remote/creation`, rabbit 공식 하드웨어 이벤트 문서, Spotify Player API.

## Brand
- 앨범아트 중심의 조용한 음악 리모컨입니다. 검정 바탕, 밝은 글자, 녹색 상태 표시를 사용합니다.
- 실제 Spotify 정보와 연결 상태를 구분하고 임의의 곡을 실제 재생 정보로 표시하지 않습니다.

## Product goals
- 현재 곡의 아트·아티스트·제목·앨범을 표시하고 스와이프·물리 버튼으로 제어합니다.
- 성공 기준: 240×282 기본 화면에 모든 주요 정보가 보이고 한 동작당 한 번만 명령을 보냅니다.
- 다른 기기의 Spotify 재생을 제어합니다. 이 앱 자체의 오디오 스트리밍은 범위 밖입니다.

## Personas and jobs
- 같은 계정의 Spotify를 재생 중인 사용자가 래빗으로 곡을 확인하고 제어합니다.

## Information architecture
- 기본 화면: Spotify 출처, 앨범아트, 아티스트, 제목, 앨범, 진행 시간과 연결 상태.
- 앨범아트 탭: 벅스에서 같은 제목·가수·곡 길이의 일반 가사를 먼저 조회하고, 없거나 실패하면 기존 LRCLIB·lyrics.ovh 조회를 사용합니다. 탭 시 실제 출처가 표시되며 시간 정보가 있으면 현재 줄을 따라갑니다.
- 가사 화면: 좌우 스와이프로 재생 화면에 복귀하고 ‘현재 가사 따라가기’ 체크박스로 자동 이동을 켜고 끕니다. 세로 탐색과 체크박스 조작은 복귀로 처리하지 않습니다.
- 가사 화면의 제목·출처·안내·따라가기 설정은 기본 숨김입니다. 탭/Enter로 3초 표시하고 다시 탭하면 숨깁니다. 체크박스 조작은 표시 시간을 연장하며, 단순 탭으로 따라가기 상태를 변경하지 않습니다. 가사 없음과 오류는 탭 없이도 표시합니다.
- 설정: 계정 연결, 연결 해제, 조작 안내. 기기에 저장한 로그인은 재실행 시 자동 복원합니다.

## Design principles
- 아트의 원래 비율과 내용을 보존합니다.
- 곡 전환·통신 오류 시 예전 가사와 제어 상태를 새 곡의 정보처럼 표시하지 않습니다.
- 앱 복귀 시 화면 크기·재생 조회·중단된 가사를 복구합니다. 전환 중 0 높이는 무시하고 이미 표시된 가사와 자유 탐색 위치는 유지합니다.
- 한 화면에 맞추되 긴 제목은 접근 가능한 전체 텍스트를 유지합니다.

## Visual language
- Color: 배경 #101211, 본문 #f5f7f5, 보조 #b3bab5, 강조 #1ed760.
- Typography: 시스템 글꼴, 제목 16px, 아티스트 12px, 앨범 11px.
- Spacing/layout: 8px 외곽 여백, 아트 약 156px 정사각형, 주요 터치 버튼 44px.
- Motion: 장식 애니메이션 없음. 현재 가사 이동은 구형 WebView 호환을 위해 scrollTop으로 즉시 처리합니다.
- Imagery: Spotify가 제공하는 앨범아트를 변형 없이 표시합니다.

## Components
- 기존 rabbit의 window 하드웨어 이벤트와 AbortController 타임아웃 패턴을 재사용합니다.
- 재생 화면에서는 휠 위/아래 입력으로 실제 Spotify 재생 기기의 볼륨을 5%씩 변경합니다. 0~100%로 제한하고 미지원 기기에 명령을 전송하지 않습니다. 연속 입력은 150ms 동안 모아 기존 재생 명령 경로에서 순서대로 처리합니다.
- 플레이어, 연결 폼, 상태 문구, 가사 화면은 기본 HTML/CSS/JS로 작성합니다.
- 로딩·연결 전·재생 없음·일시정지·오프라인·제한된 기기를 별도 상태로 표시합니다.

## Accessibility
- 이미지 설명, 화면 상태 알림, 키보드 이전/다음/재생, 명확한 포커스와 대비를 제공합니다.
- 스와이프 외에 화면 버튼과 물리 버튼으로 조작할 수 있습니다.
- 가사 자동 이동은 체크박스로 제어합니다. 직접 탐색하면 체크가 해제되며 다시 체크하면 즉시 현재 줄로 복귀합니다. 시간 정보가 없는 가사에서는 체크박스를 비활성화합니다.

## Responsive behavior
- 기준 240×282, 일반 브라우저에서는 가운데 배치합니다.
- 설정·가사는 세로 스크롤과 래빗 휠을 지원합니다. 기본 가사 화면은 전체 높이를 사용하고 탭으로 안내가 표시될 때만 설정 영역 높이를 확보합니다. 따라가기 중에는 영역 변경 후 현재 줄을 다시 표시합니다. 기본 화면은 가로 넘침이 없어야 합니다.
- 실제 WebView/visualViewport 높이를 기준으로 레이아웃을 줄입니다. 재생 버튼 행은 버튼 높이 이상을 확보하고 24px 하단 여백을 둡니다. 앨범아트 영역은 화면 높이에 맞춰 줄어들어야 합니다.

## Interaction states
- Loading: 실제 요청 중임을 표시합니다.
- Empty: Spotify에서 곡을 먼저 재생하도록 안내합니다.
- Error/offline: 마지막 정보임을 표시하고 잘못된 중복 재시도를 막습니다.
- Disabled: Spotify가 금지한 동작 또는 요청 중인 동작을 차단합니다.
- Success: API가 반환한 상태로만 재생 여부를 확정합니다.

## Content voice
- 앱 안내와 코드 주석은 정중한 문어체입니다.
- 가사 제공처와 미지원 상태를 정확하게 표시합니다.

## Implementation constraints
- 신규 UI 라이브러리 없이 브라우저 기본 기능을 사용합니다.
- rabbit에서 미지원이 확인된 AbortSignal.timeout에 의존하지 않습니다.
- 테스트는 실제 계정이나 유료 모델을 호출하지 않습니다. 브라우저 모의 시험과 실제 기기 시험을 구분합니다.
- 로그인은 래빗 보안 저장소와 기기 IndexedDB 백업으로 유지합니다. 보안 저장 응답만으로 백업을 삭제하지 않으며, 별도 백업이 없을 때에는 읽기 검증까지 필요합니다. 토큰을 localStorage·사이트 서버에 저장하지 않으며 명시적 연결 해제 기록이 예전 보안 저장값보다 우선합니다.
- 설정의 ‘기기 확인’에 음량 지원 여부·휠 수신·화면 크기·로그인 저장 결과·버전을 표시하여 실기 문제를 확인할 수 있도록 합니다.
